## 1. Feature Status Classification Definitions

* **WORKING (Evidence)**: Proven to work with passing automated test suite, E2E run, or recorded hardware execution logs.
* **PARTIAL**: Implemented in codebase, but relies on fallbacks, has unreviewed dependencies, or fails certain environmental gates.
* **NOT BUILT**: Conceptualized in designs or protocols, but zero implementation exists in the current repository commit.
* **REMOVED**: Previously existing prototype feature that was deliberately pruned to prevent dead links, security issues, or synthetic data violations.
